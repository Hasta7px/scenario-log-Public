# 通過シナリオ管理

TRPG / マーダーミステリーの通過シナリオを記録するための、単一HTMLファイルのツールです。

## 使う

GitHub Pages で公開しています（URLは下記「公開URL」参照）。
ブラウザで開くだけで使えます。インストール・ログイン不要。

## 人に見せる（共有リンク）

**「共有リンクを作る」** を押すと、記録データを圧縮して URL の `#` 以降に埋め込んだリンクがクリップボードにコピーされます。
そのリンクを DM などで渡すと、相手は**閲覧専用**でこの一覧を見られます。

- URL の `#` 以降はサーバーに送信されないため、データはこのリポジトリにも GitHub にも保存されません。検索エンジンにも出ません。
- 見られるのは**リンクを渡した相手だけ**です（ただしリンクを転送されれば誰でも開けます。厳密なアクセス制御ではありません）。
- リンクは作った時点のスナップショットです。記録を更新したら、作り直して渡し直してください。
- 相手側では追加・編集はできません。相手が自分の控えとして使いたい場合は「JSON書き出し」→ 通常のページで「JSON読み込み」。

## データについて

- 記録したデータは**閲覧しているブラウザの localStorage にのみ**保存されます。サーバーには送信されません。
- そのため**端末・ブラウザごとに別のデータ**になります。ブラウザのサイトデータを消すと記録も消えます。
- 端末間で移したいとき、またはバックアップを取りたいときは、画面の **エクスポート** で JSON を保存し、移し先の端末で **インポート** してください。

## 構成

- `index.html` — 本体。HTML / CSS / JavaScript が全部入った自己完結ファイル。外部ライブラリ・CDN 参照なし。

ビルド工程はありません。ローカルで編集して `index.html` をブラウザで直接開けば動作確認できます。
`main` ブランチに push すると GitHub Pages に自動反映されます。
